WHY — 사업 배경
PENTA
초등 문해력 프랜차이즈
이은경(교육 저자·유튜버 15만) + 이동길(시스템·경영) 공동 창업. 특허 출원 → 벤처인증 → 초창패 → 학원 오픈 → 가맹 확장. 캐시카우는 학원, 기업 밸류에이션은 테크. 2건의 특허로 "에듀테크 회사"의 IP 기반을 구축한다.
PROBLEM — 시장의 두 가지 공백
진단도 채점,
첨삭도 블랙박스
진단: 하루 시험 한 번 → 점수 하나. 아이가 어디가 약한지, 왜 약한지 모른다. 첨삭: AI에 글을 넣으면 완성본이 나온다. 학습자는 무엇이 왜 바뀌었는지 모르고 결과만 복사한다. 교사가 직접 하면 1명 30분 → 확장 불가.
SOLUTION — 펜타의 투트랙
진단은 포트폴리오,
첨삭은 파이프라인
특허 1: 1개월+ 데이터를 쌓아 패턴이 수렴하면 비로소 진단. 특허 2: 5단계(비문탈출→한자어→표현력→분량)로 분리하여 단계별 diff 비교 학습. 진단이 "어디가 약한지" 알려주면, 첨삭이 "그 부분을 집중 교정"한다.

포트폴리오 기반 다차원 문해력 종합 진단 시스템 및 방법
둘 이상의 문해력 영역 데이터를 일정 기간 포트폴리오로 축적 → NLP 다차원 분석 → 패턴 수렴 판정(σ≤δ) → 발달 단계 + 신뢰도 + 처방 출력
신규성 · 상
기존 45건 특허가 커버하지 못한 것
45건 모두 "한 번 시험 → 즉시 점수". 단일 채널. 1회분 데이터. "1개월+ 생활 데이터를 쌓아 패턴이 안정화되면 비로소 진단"하는 아이디어는 국내 45건, 해외 Lexia·Amira·Seesaw 어디에도 없다.
사업에서의 역할
펜타스쿨 프랜차이즈의 핵심 진단 엔진. "우리 아이 문해력 몇 점?" 무료 진단 → 학부모 유입 훅. 전국 데이터 축적 시 "동학년 상위 N%" 제공. 웹 서비스(진단+처방)로 온라인 수익화 가능.
다차원 데이터 수집 → NLP 분석 → 수렴 판정 구조
데이터 수집 (5종): ① 자유작문(일기·감상문) ② 주제유도작문(사회·역사 에세이) ③ 독해 문항 응답 ④ 대화 녹음(STT 전사) ⑤ 서술형 답변
NLP 분석 (4축): 독해력(추론·핵심파악) · 어휘력(일상어/한자어 분류, 학년별 충족률) · 표현력(TTR·문장길이·호응오류·논리접속어) · 사고력(논증구조·주장-근거 패턴)
수렴 판정 알고리즘 (σ≤δ): 최근 N회 측정값 표준편차 σ가 임계값 δ 이하 → 진단 확정 + 신뢰도 출력 / 미달 → "진단 보류" + 추가 데이터 요청. δ는 영역별·학습자 수준별 적응형(adaptive δ)으로 설정.

표면 겹침(텍스트분석, TTR 등)은 있으나 법적 충돌 없음 확인.

청구항 구체화 전략 — 서상철 변리사 8단계 분석 반영
구분기재 수준리스크전략
① 단순 일반화만"둘 이상의 문해력 영역을 분석"매우 높음사용 금지
③ 데이터 수집 명시텍스트·음성 등 이질 데이터 포함보통필수 포함
⑤ 결합 로직 명시다중 영역 간 상관 분석, 통합 판단낮음핵심 차별
⑥ 시계열/패턴 분석누적 데이터 기반 변화 분석낮음강력 권장
⑦ 결과 구조 명시발달 단계 + 신뢰도 산출낮음필수
독립청구항 핵심 요소
  • 이질적 데이터 모달리티(텍스트·음성·문항응답)로부터 자연 발생적 데이터를 수집하는 단계
  • 독해력·어휘력·표현력·사고력 다중 영역에 대해 NLP 기반 특징 추출 및 영역별 독립 분석하는 단계
  • 서로 다른 시점에서 수집된 N회 데이터의 표준편차 σ가 임계값 δ 이하일 때 수렴으로 판정하는 단계
  • 수렴 시 발달 단계 + 신뢰도 지수를 동시 출력하고, 미충족 시 진단 보류 상태를 유지하는 단계
  • δ를 학습자 수준 또는 데이터 분포에 따라 동적으로 설정(adaptive δ)하는 단계

학문적 근거 — 이 접근이 왜 옳은가
Valencia (1990) — 포트폴리오 평가 4원칙
다양한 증거 + 실제 교실 수행 + 학생 참여 + 지속 수집. 하루 시험 한 번으로는 진짜 실력을 알 수 없음을 최초 정립.
→ "다양한 채널로 장기간 쌓는다"는 청구항의 정당성
New London Group (1996) — Multiliteracies
문해력은 읽기 하나가 아닌 쓰기·말하기·시각·디지털 등 복합 능력. 단일 시험으로 파악 불가.
→ 4축 다차원 진단이 단일 시험을 넘어서는 근거
Swain (1985) — Output Hypothesis
쓰기·말하기(출력) 시 비로소 실력 격차가 드러남. 읽기(선지 고르기)로는 숨길 수 있음.
→ 쓴 글·대화 녹음을 주요 측정 소스로 쓰는 근거
Fuchs & Fuchs (1992) — CBM 신뢰도 연구
데이터 3회+ 수집 시 신뢰도 r≥0.80. 6주+ 진행 시 진단 품질 유의미 향상.
→ 1개월+ 반복 수집 + 수렴 기준의 심리측정학적 근거
Catts et al. (2010) — 초등 문해력 종단연구
초등 초기 문해력 프로파일이 안정화되기 전에 내린 진단은 오진율이 높음. 패턴이 안정화된 후 진단해야 정확.
→ 수렴 판정 후 진단 출력하는 설계의 종단연구 근거
Snow, Burns & Griffin (1998) — NRC 보고서
초등기 문해력은 음운·어휘·독해·유창성 등 여러 차원이 상호작용하는 복합 능력.
→ 다차원 진단이 필요하다는 국제 표준 근거

한자어 활용 — 일상어를 학술 한자어로 대체 제안
