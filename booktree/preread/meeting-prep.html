JSP + jQuery란?

서버에서 HTML 페이지를 통째로 만들어 보내는 2008~2015년 방식. 페이지 이동마다 전체 새로고침. 차트·대시보드·실시간 업데이트 구현이 극도로 비효율적. 현재 은행/관공서 레거시에서 주로 사용.

세대기술시기해당
1세대HTML + PHP/ASP2000년대 초
2세대JSP/Java + jQuery2008~2015책나무
3세대React / Next.js2016~ 현재펜타

기술 분석 핵심

책나무는 B2B(가맹점 관리)는 어느 정도 돌리고 있지만,
B2C(학부모 대면 디지털 경험)가 완전히 비어 있습니다.

홈페이지 meta description 없음, 구글 리뷰 1.0점/1개, 모바일 앱 없음.
이게 바로 우리가 채울 자리입니다.

학부모 리포트 현황 (추정)

지점SW 내부에 독서이력관리 기능이 있고, 학부모 계정으로 로그인해서 볼 수 있는 구조로 추정됩니다. 하지만:

항목책나무 (추정)리드인펜타 제안
전달 방식 학부모가 직접 로그인 수업 당일 카톡 푸시 카톡 자동 발송 + 웹 리포트
시각화 JSP 기반, 차트 미약 텍스트 숫자 나열 SVG 차트 + 게이지 + 성장 그래프
AI 코멘트 없음 없음 AI + 강사 이중 코멘트
성장 추이 누적 독서량만 없음 3개월 SVG 그래프

가능성 추정

시나리오가능성대응
최근 CTO 채용 (비공개) 중간 기술 대화 준비 필요. 하지만 합류 초기라 실적 없음
외부 개발 파트너를 CTO로 호칭 높음 외주 업체와 협업 경험 있을 수 있음. 턴키 장점 어필
특허 발명자 이서영/한혜경 중 1인 낮음 특허만 참여한 외부 인력일 가능성

인력 규모

전체 직원 10~20명. 이 중 교육 콘텐츠, 가맹 관리, 마케팅, 경영지원이 대부분.
별도 개발팀이 존재할 여력이 없는 규모입니다.

가맹 사이트를 imweb(노코드)으로 만든 것이 자체 개발 역량 부재의 직접적 증거.

09 — Q&A CHEAT SHEET

예상 질문 & 답변

기술 질문 (CTO 대응)

Q. 기술 스택이 뭔가요?
X "Moodle 오픈소스 기반입니다" (공짜라고 생각함)
O "자체 개발 LMS 엔진에 멀티테넌트 아키텍처를 적용했습니다. 콘텐츠 관리, 수료 인증, 결제 모듈이 분리된 마이크로서비스 구조입니다. 500개 이상 지사가 동시 접속해도 문제없는 설계입니다."
Q. 개발 인력이 몇 명이에요?
X "저 혼자..."
O "CTO인 저와 AI 엔지니어링 파이프라인으로 운영합니다. 기존 5~10명 팀이 3개월 걸릴 작업을 4~6주에 끝냅니다. 프로토타입은 이미 만들어왔습니다."
Q. 우리가 사람 구해서 직접 하면 안 되나요?
O "가능합니다. 다만 LMS + 결제 + 자격관리 + 리포트 시스템을 처음부터 만들면 개발자 3~5명, 6개월 이상, 인건비만 1.5~2억입니다. 저희는 이미 돌아가는 시스템을 이식하는 거라 기간과 비용이 1/3입니다."
Q. 기존 BToS / 지점SW와 연동 가능한가요?
O "현재 시스템 API 스펙을 공유해주시면 데이터 연동 가능합니다. 기존 독서이력 데이터를 새 시스템으로 마이그레이션하는 것도 범위에 포함되어 있습니다."
Q. 현재 시스템이 JSP인데, 새 시스템도 Java 기반인가요?
O "새 시스템은 현대적인 아키텍처(React/Next.js)로 구축합니다. 기존 JSP 시스템 위에 올리는 게 아니라 독립 플랫폼으로 제공하므로, 기존 시스템 운영에 영향 없이 병행 가능합니다."

비즈니스 질문 (대표 대응)

Q. 다른 곳에 구축 경험이 있나요?
O "현재 펜타캠퍼스 자체 원격연수원을 구축 중이고, 교원 직무연수 인가 절차를 진행하고 있습니다. 동일 아키텍처를 책나무에 맞게 커스터마이징하는 구조입니다. 자체 연수원을 먼저 만들고, 검증된 시스템을 책나무에 턴키로 납품하는 방식입니다."
Q. 이은경 대표가 연수 과정을 직접 강의하나요?
O "이은경 대표가 핵심 과정을 직접 설계하고, 일부 과정은 직접 강의합니다. 추가로 분야별 전문 강사를 섭외해서 5개 과정을 구성합니다. 이은경 대표의 SNS(유튜브 15만, 저서 60권)를 통한 수강생 유입도 기대할 수 있습니다."
Q. 유지보수는 어떻게 되나요?
O "구축 완료 후 2개월간 운영 코칭이 포함되어 있고, 이후에는 월정액 유지보수 계약으로 전환합니다. 장애 대응, 콘텐츠 업데이트, 시스템 개선이 포함됩니다."
Q. 학부모 리포트도 같이 해줄 수 있나요?
O (폰 꺼내며) "네, 이미 책나무 브랜드로 만들어봤습니다. 이것은 대표님 특허에 명시된 기능이기도 합니다. 원격연수원과 별개로 제안 가능합니다."
Q. 비용이 좀 있는데, 분할 납부 가능한가요?
O "마일스톤 기반 분할 납부가 가능합니다. 착수 시 30%, 중간 검수 시 40%, 납품 완료 후 30% 구조로 진행합니다."

위험 질문 (방어)

Q. 오픈소스(Moodle) 기반 아닌가요?
O "핵심 LMS 엔진은 검증된 오픈소스 프레임워크를 기반으로 하되, 책나무 전용 기능(자격 체계, 지사별 관리, 수료 인증)은 100% 커스텀 개발입니다. 인프라 안정성은 오픈소스의 장점을 활용하고, 차별화 기능은 자체 개발로 가는 하이브리드 전략입니다."
Q. 펜타라는 회사가 처음 들어보는데, 신뢰할 수 있나요?
O "이은경 대표는 초등 교육 분야에서 60권의 저서와 15만 유튜브 구독자를 가진 검증된 전문가입니다. CTO인 제가 교대 출신 교육경력 15년에 EdTech 시스템 아키텍처를 직접 설계합니다. 펜타캠퍼스 자체 연수원을 동시에 구축 중이고, 저희가 먼저 쓰는 시스템을 책나무에 납품하는 구조입니다."
